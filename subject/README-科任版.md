給**在自己專科教室上課**的科任老師使用（音樂、自然、英語、美勞教室等）。一台電腦、一個大螢幕，可以存好幾個班級，切換班級時，座號、任務魚、水族箱、圖鑑、聯絡簿都會跟著換。

整個程式只有一個檔案：`subject-dashboard.html`。其他功能和導師版相同，請參考導師版的 README。

---

## 第一次使用

1. 打開網頁，會出現「建立第一個班級」。
2. 輸入班級名稱（例如「五年甲班」）、最大座號（1～50 號），有跳號就填空號（例如 `7、15`），再選一個代表色。
3. 「任務魚進化份數」會自動填成實際人數的一半。科任課一週只上一兩次，用全班人數的份數要好幾週才會進化，可以自己調整。
4. 按「建立」就完成了。

## 新增、切換班級

- 點右上角的**班級名稱 ▾**，會列出所有班級，每一班顯示人數、圖鑑種類和魚的數量。
- 點一個班級就切換過去，畫面中央會大大顯示「現在上課的班級」。
- 最下面「＋ 新增班級」可以再加班級，數量沒有限制。
- 每一列右邊的 ✎ 可以改班名、換顏色，或刪除這個班級（會再確認一次）。
- 任務魚正在進化時不能切換，等動畫結束再換。

## 哪些各班分開、哪些全部共用

| 每班各自一份 | 全部班級共用 |
|---|---|
| 人數、座號、空號、打卡 | 作息表 |
| 任務（最多 3 個）、任務魚、水族箱、圖鑑、金幣 | 倒數日 |
| 聯絡簿（例如「五甲下週帶直笛」） | 天氣、時區 |
| 抽號紀錄、個人點數與兌換紀錄 | 倒數計時、番茄鐘、點數兌換品清單 |
| | 環境音、效能模式、音效、注音、跑馬燈、天氣地點、版面加寬、音量偵測的界線 |

打卡區的上緣會換成班級顏色，右上角也一直顯示班名。

每個班可以各自同時進行最多 3 個任務、各自設定空號，用法和導師版相同（見導師版 README 的「同時進行多個任務」「座號跳號（空號）」）。

## 巨鯨里程碑

和導師版一樣，每個班的飼料累積到門檻時會有巨鯨游過畫面，各班分開計算。因為科任課次數比較少，門檻改成：300 份雙吻前口蝠鱝、600 份大翅鯨、1200 份抹香鯨、1800 份藍鯨，每隻只出現一次。

## 注音

左上角「ㄅ 注音」按鈕和導師版一樣：學生要自己讀的內容（聯絡簿、作息節次、任務名稱、倒數日、星期、抽號結果、魚名、進化卡片）加上注音，切換班級時的大班名也會有注音。

注音的開關和字型（圓體／楷書，在教師控制台「特殊」分頁切換）是**所有班級共用**的，切換班級後不用重新開啟。

## 備份與還原

- 教師控制台 →「特殊」→「下載備份檔」，**一次備份全部班級**，檔名會寫有幾個班，例如 `科任儀表板備份_6個班_20261102_1042.json`。
- 「從備份檔還原」選擇科任版的備份檔，會把所有班級還原成備份當時的樣子。
- 如果選的是**導師版**的備份檔，會匯入成一個新的班級（名稱為「匯入的班級」，可以再改名），其他班級不受影響。
- 「重置：清除全部資料」會清除所有班級，會詢問兩次。

## 和導師版放在同一個網站

科任版和導師版的資料分開儲存，放在同一個網站（例如同一個 GitHub 儲存庫）也不會互相覆蓋。

- 導師版：`index.html`
- 科任版：放在 `subject` 資料夾裡、改名為 `index.html`（網址是 `…/classdashboard/subject/`）
