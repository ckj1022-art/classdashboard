# 班級儀表板 Class Dashboard

教室大螢幕用的班級儀表板：大時鐘、作息表、聯絡簿、倒數與番茄鐘、抽號、音量偵測，還有全班一起養魚的任務打卡。免安裝、免帳號，打開就能用。
